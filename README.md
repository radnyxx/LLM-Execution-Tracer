# 🌐 LLM Execution Tracer & Visualizer

An interactive web application that pulls back the curtain on Large Language Models. This tool visualizes the background processes—from prompt processing to token decoding—that occur when an LLM generates a response.

**🔗 Live Demo:** [https://llm-visualizer-v1.vercel.app/](https://llm-visualizer-v1.vercel.app/)

---

## 🚀 What is this?

Most users only see the final text generated by an AI. This tracer visualizes the logic and execution steps that happen in the background. Simply enter a prompt, and the app maps out the sequence of operations the LLM performs to decode your request and formulate its response.

### ✨ Key Features
*   **Step-by-Step Visualization:** Watch the background logic unfold as the LLM processes your prompt.
*   **Decoding Insights:** Gain a clearer understanding of how tokens are predicted and strings are formed.
*   **Real-time Interaction:** Submit any prompt and see a unique execution trace generated on the fly.
*   **Clean UI:** A minimalist interface focused on making complex AI behaviors easy to digest.

## 🚦 Getting Started

To run the visualizer locally for development:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/llm-execution-tracer.git](https://github.com/your-username/llm-execution-tracer.git)
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Launch the dev server:**
    ```bash
    npm run dev
    ```

4.  **View the app:**
    Navigate to `http://localhost:3000` in your browser.
