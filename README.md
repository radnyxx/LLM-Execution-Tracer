## LLM EXECUTION TRACER

An interactive visualizer designed for educational purposes to demystify how Large Language Models (LLMs) read, process, and respond to prompts. 

Many people treat AI as a "magic wand." This tool peels back the background layer to provide a clear, step-by-step visual workflow of the generation process without overwhelming users with math-heavy equations or limiting the view to a single phase like tokenization.

## Features

* **Interactive Flow:** Follow the pipeline from initial text prompt to final model output.
* **End-to-End Visibility:** Bridges the gap between standalone steps to expose the entire underlying mechanics.
* **Designed for Education:** Built with an intuitive UI optimized for students, developers, and AI enthusiasts looking for visual intuition over heavy mathematics.
